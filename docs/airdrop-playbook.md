# Arc Contribution Playbook

No one outside the Arc team can promise airdrop eligibility. Treat the goal as making a visible, useful contribution first.

## High-Signal Work

1. Ship a repo that other builders can run in under 10 minutes.
2. Include Arc-specific details, not generic EVM boilerplate.
3. Deploy on Arc Testnet and publish explorer links.
4. Show real testnet usage: create job, submit deliverable, approve payout.
5. Write a short thread or community post explaining what problem the repo solves.
6. Keep a public changelog and respond to feedback.

## Suggested Next Improvements

- Add a small Next.js dashboard for job creation and event history.
- Add ERC-8004 identity lookup so each agent can attach onchain identity metadata.
- Add an ERC-8183 adapter once the interface and reference contracts are stable for your use case.
- Add event indexing with The Graph, Envio, Goldsky, or Thirdweb.
- Add support for ERC-20 USDC allowances where `transferFrom` is more appropriate than native `msg.value`.

## Evidence To Keep

- Git commit history
- GitHub issues and pull requests
- Test output
- Deployment address
- Explorer links
- Faucet funding transaction
- Demo job transactions
- Community feedback
