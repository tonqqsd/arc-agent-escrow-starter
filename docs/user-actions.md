# Actions The User Must Complete

I can build, test, document, and prepare the submission assets locally. You need to handle the steps that require your accounts, wallet, or public posting.

## Required

1. Create or use an Ignyte Challenges account.
2. Join **The Stablecoins Commerce Stack Challenge**.
3. Create or use a Circle Developer account and keep the account email for the submission form.
4. Create a fresh Arc Testnet wallet.
5. Add that wallet private key only to local `.env`; do not paste it in chat.
6. Request Arc Testnet USDC from the Circle Faucet.
7. Deploy the contract with `npm run deploy:arc`.
8. Publish the repo to GitHub.
9. Deploy the demo frontend/API to a public URL.
10. Record and upload a demo video.
11. Submit the Ignyte form with the submission document, GitHub URL, and video URL.

## Optional But Helpful

- Request access to gated Circle products if you want to mention a real StableFX or USYC integration.
- Create at least one live job and approve or dispute it before recording the video.
- Share the project in Arc or Circle community channels after submission.
